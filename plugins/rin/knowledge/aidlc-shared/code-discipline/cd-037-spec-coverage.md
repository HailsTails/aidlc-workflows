Every change traces to an entry in the active plan's task list — no orphan work. A drive-by edit with no task behind it collapses the coherence between intent, design, and execution that planning exists to hold. The only latitude is a pure typo or formatting touch in a file the plan already covers; anything that alters logic is new planned work.
